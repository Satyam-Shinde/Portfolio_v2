# Satyam Portfolio React

Static React + Vite + Tailwind CSS version of the supplied portfolio.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Data

All portfolio content lives in:

`src/data.js`

No backend or API is required. Replace the values in `src/data.js` with your own data later.

## Main files

- `src/data.js` - static JSON-style data
- `src/App.jsx` - React UI
- `src/index.css` - Tailwind + custom theme/grid/animation styles
- `vite.config.js` - Vite + Tailwind setup
